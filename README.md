# 🐍 Snake Game

A classic Snake Game built using **Python** and **Pygame** with a polished and realistic visual style.

The game includes multiple difficulty levels, a sequential fruit system, score tracking, animated effects, boundaries, and keyboard controls.

---

## 🎮 Features

- 🎯 Three difficulty levels:
  - Easy
  - Medium
  - Hard
- 🐍 Connected and visually detailed snake
- 🍎 Sequential fruit system:
  - Apple
  - Banana
  - Grapes
  - Orange
  - Then repeats
- 🧱 Stone-style game boundary
- 🌿 Dark grass-style game background
- ✨ Fruit glow effect
- 💥 Eating particle effects
- 👀 Detailed snake head with eyes
- 👅 Snake tongue animation
- 🏆 Score tracking
- 🎮 Keyboard controls
- 💀 Game Over screen
- 🎨 Polished game UI

---

## 🛠️ Technologies Used

- **Python**
- **Pygame CE**
